# 配信機能があるアプリに音声のみの双方向通話を追加する方法を検討する

- Created: 2026-09-11
- Completed: {YYYY-MM-DD}
- Branch: feature/debug-audio-only-bidirectional
- Polished: {YYYY-MM-DD}

## 目的

既に配信機能 (映像と音声の送信) があるアプリに、音声のみの双方向通話を追加したいという需要がある。Discord の音声通話に OBS のような配信ツールを組み合わせる使われ方を想定しており、SDK としてどう実現するかを検討する。

## 現状

- `Sora.Config` には `Role` / `Video` / `Audio` があり、音声だけを送受信する接続自体は設定で表現できる。
- 一方で、配信 (送信) と通話 (双方向) を同時に扱う構成や、用途ごとに接続を使い分ける構成は SDK として整理されていない。
- 音声通話の音声をそのまま RTMP などで配信する使い方を想定すると、何を SDK が担い、何をアプリ側が担うかを決める必要がある。

## 設計方針

- Sora C++ SDK 側の知見を持つ担当と相談し、音声のみの双方向通話を既存の配信機能とどう組み合わせるかを整理する。
- 1 接続で送受信を切り替えるのか、用途ごとに接続を分けるのかを比較検討する。
- アプリ側で実装すべき範囲と、SDK が提供すべき範囲を切り分ける。

## 完了条件

- 音声のみの双方向通話を追加する方法が整理され、採用する構成が決まっている。
- SDK として対応が必要な範囲が明確になっている。
- 対応が必要な場合は個別の実装 issue が起票されている。

## pending にした理由

2026-09-11 に pending にする。

- 実現方法が方針レベルにとどまっており、Sora C++ SDK 側の知見を持つ担当との相談が必要である。
- 音声のみの双方向通話と既存の配信機能をどう組み合わせるかの設計判断が必要で、その結論が出るまで実装に着手できない。
- アプリ側と SDK 側の責務分担が決まっていない。
